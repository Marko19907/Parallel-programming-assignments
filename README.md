# Parallel Programming Assignments

This repository contains the semester assignments for the Parallel Programming (TDT4200) course at NTNU, autumn 2024.

## Contents

### Mandelbrot Fractal Visualization

This assignment involves creating visual representations of Mandelbrot fractals using both sequential and CUDA implementations. 

### Wave Simulation

The wave simulation assignments involve solving the 2D wave equation using various parallel programming paradigms. 

https://github.com/user-attachments/assets/5d4c1ef0-b4f4-4cfd-91fe-49e3c39e4614

The following implementations are included:

* Sequential
* MPI
* OpenMP
* PThreads
* CUDA
